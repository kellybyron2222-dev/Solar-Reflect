# Civil-night 3D explorer

Toggles the E6–E8 cases. Not a product shot. Foils are enlarged 900×; the ground ellipse is true kernel \(D\) (F15). Drawn count is the \(N_T\) train spaced by \(T_\text{useful}\), or an \(N_I\) cluster when \(N_T=1\).

Needs HTTP (import map + `cases.json`). From the project root:

```text
python whiteboard/serve.py
```

Then open http://127.0.0.1:8765/figures/explorer/

If that port is already taken:

```text
python whiteboard/serve.py --port 8766
```

and use http://127.0.0.1:8766/figures/explorer/

`cases.json` is generated by `python figures/explorer/build_cases.py` from `physics.py`.
