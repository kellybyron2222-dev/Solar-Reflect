# Phase H — Draft (detailed outline)

**Depends on:** frozen `figures/report/` after Look-back X  
**Produces:** `report.md` (or Typst/LaTeX if you prefer; one source)  
**Do not produce:** new numbers, new figures, new claims

---

## Why this phase exists

The report is a summary of F, illustrated by X, scoped by G. If H is interesting in a way F was not, H has drifted.

---

## Work sequence

### H0. Re-evaluate from G, F, and X (before writing)

The draft’s scope is the intersection of surviving claims (F/G), frozen figures (X), and frozen intent. H does not get a better story.

1. Open `carry/F_to_G.md`, `scope.md`, `carry/X_to_H.md`, captions, assessment.
2. Write `carry/H_scoped.md`: section map (which F5 claims in which section); figure IDs; appendix = C3/E2 example. If F dropped a claim, it does not reappear as a punchy close.
3. Keep `assessment.md`, `results_book.md`, `scope.md`, and `captions.md` open. If a sentence needs a number not in those files, **stop H** and return to E (then F, G, X as needed).

Typical G/X→H impacts:

| If upstream concluded… | Then H… |
|---|---|
| Applications are readout | They stay last |
| No 3D | No “see the orbit” paragraph that needs a globe |
| Fluence is an upper bound | Appendix and body say so |
| Markers are illustrations | Title and lead do not name a product |

### H1. Place figures first

Insert G’s figures with X captions. Do not rewrite captions to be punchier if that changes the claim.

### H2. Appendix first (numbers)

Copy the C3/E2 625 km worked example (M18, M55, ideal and realistic \(I\), \(D\)). This is the calculator trail. Do not re-derive with different rounding.

### H3. Body order (fixed)

1. **Mechanism** — what is redirected; S-geo-2d. No applications.  
2. **Governing facts** — energy; extended Sun / \(D=h\alpha\); \(I \propto A/h^2\); shutter. S-spot-h, S-focus.  
3. **Limits** — required \(A\), dwell, fluence as upper bound. S-I-A, S-A-req, S-dwell. This is the spine.  
4. **Applications (readout)** — A5 table vs markers; peak column and duration column separate.  
5. **Close** — requirements, not markets. Pointer that open items live in F4.

Title last. Title must not name a company or a product.

### H4. Voice

Thought experiment / technical note. SI in the body. Lux only as an aside in the illumination row if at all. Short sentences.

### H5. Revision

Check each paragraph against F5 pointers. If prose “fixes” a plot, revert the prose.

---

## Look-back H (close)

1. **Intent.** Still a physics-first analysis of delivering reflected sunlight? Not a rendering demo, not a business case?
2. **Plan.** Extra figure? Extra \(I^*\)? Extra geometry? Undo or framed rewind.
3. **Honesty.** Every number in results book or appendix. Every figure in `figures/report/`.
4. **Ready.** There is no next analysis phase. Stop.

Checklist:

- [ ] Order: mechanism → facts → limits → applications → close
- [ ] Appendix = C3/E2 example
- [ ] Claims ⊆ surviving F5
- [ ] No cost, no firm as subject, no beam
- [ ] Open items not converted into conclusions
- [ ] Master-outline v1 vs later table respected (no surprise 3D)

**Done.** Do not start a 3D workbench unless you amend frozen intent and re-run from A.
