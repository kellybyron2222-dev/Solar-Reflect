# Phase G — Report scoping (detailed outline)

**Depends on:** `assessment.md` after Look-back F  
**Produces:** `scope.md`  
**Do not produce:** new calculations, new scene IDs, draft chapters

---

## Why this phase exists

The report is allowed to be smaller than the assessment. It is not allowed to be different physics.

---

## Work sequence

### G0. Re-evaluate from F (before picking audience)

F’s claims and open items set what the report is allowed to be. G may shrink. G may not invent.

1. Open `assessment.md` and `carry/F_to_G.md`. If carry is missing, stop.
2. Diff the default figure list against what E/D actually produced and what F actually uses.
3. Write `carry/G_scoped.md`: audience; claim IDs in; claim IDs out (and why — usually F4); figure IDs in. If F said Ω is N/A, the report does not lead with “you cannot focus onto a farm” unless F5 has that claim.
4. Then fill `scope.md` from the scoped plan, not from the default six-figure wish list.

Typical F→G impacts:

| If F concluded… | Then G… |
|---|---|
| Energy and shutter bind; étendue is N/A for A5 classes | Do not center the essay on shrinking the spot |
| Several F5 claims tied to open items | Drop them from the public claim list |
| S-focus was load-bearing in F | Keep it in the figure list |
| Assessment is short | Length band stays short; do not pad with 3D |

### G1. Audience

Pick one:

- **G-self:** note to future you (can keep more tables).
- **G-technical:** technically literate, not a specialist (fewer tables, more S-geo-2d / S-focus).

Do not pick “general public viral thread” in v1; it pulls drawings you do not have.

### G2. Surviving claims

List F5.n IDs that survive. Drop any claim whose pointer is an open F4 item.

### G3. Figure list

Choose a **subset** of scenes that actually exist in `figures/working/`.

Default proposal (edit after seeing F, do not treat as pre-decided art direction):

- S-geo-2d  
- S-spot-h  
- S-I-A (with \(I^*\) lines only if E5 built that copy)  
- S-A-req  
- S-dwell  
- S-focus  

Max: those six. Prefer fewer. **Zero 3D.**

If you want a watt-chain or farm overlay, you must have built it in E under a framed change. G cannot order it.

### G4. Shape

- Lead: mechanism + facts + limits.  
- Applications: one table after limits.  
- Markers M18/M55: examples in that table, not the title.  
- Length: set from F’s bulk (e.g. “assessment is N pages of claims → essay ~2–4× the claims section”). Do not reuse an old 3–4k target unless it still fits.

### G5. Write `scope.md`

```
Audience:
Surviving claims: F5.x, ...
Figures: [IDs]
Applications: table / short section after limits
Markers: illustration yes/no
Length band:
Out of report: (F4 items, diligence internals, working chrome)
```

### G6. Carry to X

Write `carry/G_to_X.md`: exact figure ID manifest; nothing else to export.

---

## Look-back G (required)

1. **Intent.** Does the proposed essay still put physics first?
2. **Plan.** Any figure ID not on disk? Any new claim? No-go.
3. **Honesty.** Open items excluded or clearly “we did not model.”
4. **Ready.** Phase X is a copy job, not a design job.

Checklist:

- [ ] `scope.md` exists
- [ ] Figure IDs ⊆ working figures
- [ ] Claims ⊆ F5
- [ ] No satellite-over-farm commission
- [ ] No 3D
- [ ] `carry/G_to_X.md` exists (manifest of figure IDs only)

**Go:** boxes true → Phase X. X opens `carry/G_to_X.md` first.
